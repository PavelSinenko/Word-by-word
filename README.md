# Word-by-word

Word-by-word game.
Игра "Слово за слово" на языке C с графическим интерфейсом.

## Описание

Игроку предлагается придумать слово на русском языке, которое должно содержать определенную выпавшую на кубике букву на определенной выпавшей позиции. 
Например, если выпала "буква 'а' на позиции 2, то игрок должен придумать слово, в котором вторая буква будет 'а', например "мама", "папа", "сало" и т.д.

## Игровая механика

- Кубики с буквами содержат 10 наборов по 6 русских букв каждый
- Кубик с позициями: 3 позиции — первая, вторая, последняя 

## Принцип игры

1. Программа случайно выбирает набор кубиков и позицию, отображает их в графическом интерфейсе
2. Игрок вводит слово через текстовое поле
3. Слово приводится проверяется через онлайн-словарь Wiktionary API
4. Выводится результат:
   - «Поздравляю! Слово подходит» — слово существует и буква на позиции есть в наборе кубиков
   - «Слово не найдено в словаре» — слово отсутствует в Wiktionary
   - «Слово есть, но буква не подходит» — слово существует, но буква не совпадает

## Особенности

- Графический интерфейс на GTK+ 3.0
- Проверка слов через бесплатный Wiktionary API 
- Корректная обработка кириллицы 
- Поддержка ввода слов любого регистра
- Имеется встроенное окно с правилами игры
- Для проверки слов требуется подключение к интернету
