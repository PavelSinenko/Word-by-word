# Word-by-word
Word-by-word game in C.
Игра "Слово за слово" на языке C.

Игроку предлагается придумать слово на русском языке, которое должно содержать определенную выпавшую на кубике букву на определенной выпавшей позиции. 
Например, если выпала "буква 'а' на позиции 2, то игрок должен придумать слово, в котором вторая буква будет 'а', например "мама", "папа", "сало" и т.д.

В игре пока есть два "кубика": один с буквами, другой с позициями. 
- Кубик с буквами содержит 6 русских букв: а, б, в, г, д, е
- Кубик с позициями содержит 3 позиции: 1, 2, 3

Принцип игры:
1. Игроку выводятся сообщения с выпавшими буквой и позицией.
2. Игрок вводит слово через терминал.
3. Введенное слово проверяется через онлайн-словарь Yandex.
4. Выводятся сообщения о том:
   - есть ли вообще такое слово в словаре
   - если такое слово есть и выпавшая буква и позиция совпадают с введенным словом, то игрок молодец 
   - если не совпадают, значит игрок придумал неподходящее слово

В целом, это простая игра, которая позволяет игроку тренировать свою способность придумывать слова, которые соответствуют определенным условиям.

Примечания:
- Игра поддерживает только русские слова, так как использует русский словарь Yandex для проверки слов.
- В игру планируется добавить больше кубиков с буквами, позицию "последняя буква в слове" или "П", интерфейс для удобства игры. 
- Это базовая версия игры, которая проверяет слово через онлайн-словарь и сравнивает букву на нужной позиции с требуемой буквой из кубика.
